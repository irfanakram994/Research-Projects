# 3D Human Pose Estimation using YOLO11

This project performs human pose estimation using YOLO11 Pose.

## Features

- Human keypoint detection
- Pose visualization
- Joint angle calculation
- Video processing
- Exercise analysis

## Technologies Used

- Python
- YOLO11 Pose
- OpenCV
- NumPy
- Matplotlib
- Google Colab
